# PPE Detection 🦺

Real-time detection of personal protective equipment — helmet, safety vest, mask,
gloves, goggles, safety shoes — with a YOLO11 model, running on **CPU** via ONNX.

Upload an image or a short video to try it. Trained on ~12k images
(~0.81 mAP@0.5 on held-out test data).

Source & full write-up: see the project repository.
